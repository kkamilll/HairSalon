# Atelier Julia - Salon Fryzjerski

Prosty, statyczny i elegancki landing page dla salonu fryzjerskiego dla kobiet "Atelier Julia".

## Opis projektu

Strona została stworzona jako internetowa wizytówka salonu. Zawiera podstawowe informacje, takie jak: sekcję o właścicielce, opis usług, galerię oraz dane kontaktowe wraz z mapą. Aplikacja jest w pełni responsywna i posiada prosty mechanizm zmiany języka (Polski, Angielski, Ukraiński) napisany w czystym JavaScript. Na stronie znajduje się również autorski slider z usługami.

## Technologie

- **HTML5**
- **CSS3** (Czysty CSS bez preprocesorów)
- **JavaScript** (Vanilla JS, bez zewnętrznych bibliotek)

## Uruchomienie

Aby uruchomić projekt lokalnie, nie ma potrzeby instalacji żadnych zależności czy serwerów. Wystarczy otworzyć plik `index.html` w dowolnej współczesnej przeglądarce internetowej.

## Struktura

- `index.html` - główna struktura HTML
- `styles.css` - kaskadowe arkusze stylów definiujące wygląd strony
- `script.js` - skrypty JavaScript odpowiadające m.in. za działanie slidera, menu mobilnego, płynnego przewijania i zmiany wersji językowych.
