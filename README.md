# Atelier Julia — Hair Salon Landing Page

A modern, elegant, and responsive landing page website for **Atelier Julia**, a premium women's hair salon.

---

## 📖 Short Description

> **Atelier Julia** is a lightweight, responsive, and multilingual (PL / EN / UA) landing page for a women's hair salon, built with pure HTML5, CSS3, and Vanilla JavaScript.

---

## ✨ Features

- **Multilingual Support (i18n)**: Seamless client-side language switching between Polish (PL), English (EN), and Ukrainian (UA) without external libraries.
- **Custom Interactive Services Slider**: Touch-friendly, draggable carousel supporting swipe gestures on mobile and drag on desktop.
- **Scroll Reveal Animations**: Dynamic fade-in on scroll powered by modern `IntersectionObserver` API.
- **Interactive Micro-animations**: Mouse tracking parallax effects on the hero banner.
- **Mobile First & Responsive**: Optimized navigation with hamburger drawer menu and flexible grid/flexbox layouts.
- **Direct Booking & Social Integration**: Instant links to Booksy online booking platform, Instagram, and Facebook.
- **Zero Dependencies**: 100% Vanilla JS and native CSS with zero build steps or third-party runtime dependencies.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup with SEO meta tags
- **CSS3** — Modern styling, CSS variables, Flexbox & CSS Grid, smooth transitions
- **Vanilla JavaScript (ES6+)** — Slider logic, mobile navigation, scroll animations, and i18n dictionary system
- **Google Fonts** — *Inter* & *Cormorant Garamond*

## 🚀 Getting Started

No build step, package manager, or server installation is required.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kkamilll/atelier-julia.git
   ```
2. **Open the project**:
   Simply open `index.html` in any modern web browser or use a local live server (e.g. VS Code Live Server extension).
